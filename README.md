# YouTube 영상 유해성 분석 웹앱

> 2025 캡스톤디자인 프로젝트

YouTube 영상의 음성을 텍스트로 변환하고, 유해 단어 탐지와 AI 감성 분석을 결합해 영상의 시청 연령 등급을 자동으로 판정하는 웹 서비스입니다.

## 개요

- YouTube URL을 입력하거나 영상 파일을 업로드하면, 음성을 추출해 **Whisper**로 텍스트를 생성합니다.
- 변환된 텍스트에서 **유해 단어 사전** 기반으로 욕설·혐오·차별·폭력 표현을 찾아 점수화합니다.
- 문장 단위로 **한국어 감성 분석 모델(KcBERT)** 을 적용해 부정 문장을 판별합니다.
- 두 결과를 합산해 **7세 / 12세 / 15세 / 19세** 이용가 등급을 표시하고, 근거가 된 단어와 문장을 함께 보여줍니다.
- 관리자가 AI 판정 결과를 검수하면 학습 데이터(CSV)로 축적되어 모델 재학습에 활용됩니다.

## 기획 의도

- YouTube에는 연령 등급이 표시되지 않는 영상이 많아, 보호자나 시청자가 영상을 보기 전에 유해성을 판단하기 어렵습니다.
- 사람이 영상을 직접 보고 판단하는 방식은 시간이 많이 들고 기준이 사람마다 다릅니다.
- 이 프로젝트는 영상의 **발화 내용**을 기준으로 유해성을 자동 분석해, 시청 전에 참고할 수 있는 객관적인 등급과 근거를 제공하는 것을 목표로 합니다.
- 단순 욕설 필터링을 넘어, 욕설이 없더라도 공격적이거나 부정적인 맥락을 AI 감성 분석으로 함께 고려하도록 설계했습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 영상 분석 | YouTube URL 입력 또는 영상 파일 업로드 → 음성 추출(yt-dlp) → 텍스트 변환(Whisper) |
| 유해 단어 탐지 | 카테고리(욕설/혐오/차별/폭력)와 가중치가 있는 유해 단어 사전으로 점수 산출 |
| 감성 분석 | Whisper 세그먼트(문장) 단위로 긍정·중립·부정 확률 계산 |
| 연령 등급 판정 | `유해 단어 점수 × 2 + 부정 문장 수`로 7/12/15/19세 등급 결정 |
| 결과 상세 | 전체 자막, 검출된 유해 단어, 부정 확률이 높은 문장 표시 |
| 모델 비교 | 같은 영상을 다른 감성 분석 모델로 분석한 결과 비교 |
| 관리자 검수 | 문장별 AI 판정을 사람이 검수 → `verified_data.csv`로 자동 저장 → 재학습 데이터로 활용 |
| 회원 기능 | 회원가입, 로그인, 마이페이지(분석 기록) |

## 기술 스택

- **Backend:** Python, Django 5.2, SQLite
- **AI / ML:** OpenAI Whisper (medium), Hugging Face Transformers, PyTorch, scikit-learn
- **감성 분석 모델:** beomi/kcbert-large (파인튜닝), klue/roberta-large (비교 실험)
- **음성 추출:** yt-dlp
- **Frontend:** Django Template, JavaScript, CSS

## 모델 성능

직접 라벨링한 약 1,960개 문장(긍정·중립·부정 3분류)으로 학습했습니다.

| 모델 | 데이터 균형화 | 정확도 (Test) | F1-Score (Weighted) |
| --- | --- | :---: | :---: |
| beomi/kcbert-large (학습 전) | - | 0.307 | 0.290 |
| **beomi/kcbert-large (파인튜닝)** | Oversampling | **0.900** | **0.899** |

상세 학습 로그와 혼동 행렬은 [evaluation_results.txt](evaluation_results.txt)에서 확인할 수 있습니다.

## 실행 방법

```bash
# 1. 패키지 설치 (Whisper와 yt-dlp를 위해 ffmpeg가 별도로 필요합니다)
pip install -r requirements.txt

# 2. DB 생성 및 유해 단어 사전 등록
python manage.py migrate
python manage.py import_badwords

# 3. 관리자 계정 생성 (검수 기능 사용 시)
python manage.py createsuperuser

# 4. 개발 서버 실행 (PowerShell 기준, 로컬 개발 시 DEBUG 활성화)
$env:DJANGO_DEBUG = "True"; python manage.py runserver
```

환경변수 목록은 [.env.example](.env.example)을 참고하세요.
