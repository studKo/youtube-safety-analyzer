# YouTube 영상 유해성 분석 웹앱

2025 캡스톤디자인 프로젝트

YouTube 영상의 음성을 텍스트로 바꾼 뒤 유해 단어 탐지와 AI 감성 분석을 함께 적용해 시청 연령 등급을 자동으로 판정하는 웹 서비스입니다.

## 개요

사용자가 YouTube 주소를 입력하거나 영상 파일을 올리면 먼저 음성만 추출해 Whisper로 텍스트를 만듭니다. 이렇게 얻은 텍스트에서 유해 단어 사전을 기준으로 욕설과 혐오 표현 및 차별과 폭력 표현을 찾아 점수를 매깁니다. 이와 별도로 문장마다 한국어 감성 분석 모델(KcBERT)을 적용해 부정적인 문장을 골라냅니다.

두 결과를 합산해 영상을 7세와 12세와 15세와 19세 이용가 중 하나로 판정하고 판정의 근거가 된 단어와 문장을 함께 보여줍니다. 관리자가 AI의 판정 결과를 검수하면 그 내용이 학습 데이터로 쌓이고 이후 모델을 다시 학습할 때 활용됩니다.

## 기획 의도

YouTube에는 연령 등급이 표시되지 않은 영상이 많습니다. 그래서 보호자나 시청자가 영상을 보기 전에 내용이 괜찮은지 판단하기가 어렵습니다. 사람이 영상을 처음부터 끝까지 보고 판단하는 방법도 있지만 시간이 많이 들고 사람마다 기준이 다르다는 한계가 있습니다.

저희는 영상에서 실제로 오가는 말을 기준으로 유해성을 자동으로 분석하면 시청 전에 참고할 수 있는 등급과 근거를 빠르게 제공할 수 있다고 생각했습니다. 또 단순히 욕설만 걸러내는 방식으로는 욕설 없이 공격적이거나 부정적인 말을 놓치게 됩니다. 그래서 단어 탐지에 AI 감성 분석을 더해 문장의 맥락까지 함께 판단하도록 설계했습니다.

## 주요 기능

- **영상 분석:** YouTube 주소를 입력하거나 영상 파일을 올리면 yt-dlp로 음성을 추출하고 Whisper로 텍스트를 만듭니다.
- **유해 단어 탐지:** 욕설과 혐오와 차별과 폭력으로 나뉜 유해 단어 사전에 단어별 가중치를 두고 점수를 계산합니다.
- **감성 분석:** Whisper가 나눈 문장 단위로 긍정과 중립과 부정 확률을 계산합니다.
- **연령 등급 판정:** `유해 단어 점수 × 2 + 부정 문장 수`를 기준으로 7세부터 19세까지 등급을 정합니다.
- **결과 상세:** 전체 자막과 검출된 유해 단어 그리고 부정 확률이 높은 문장을 보여줍니다.
- **모델 비교:** 같은 영상을 서로 다른 감성 분석 모델로 분석한 결과를 나란히 비교합니다.
- **관리자 검수:** 관리자가 문장별 AI 판정을 검수하면 `verified_data.csv`에 자동으로 저장되어 재학습 데이터로 쓰입니다.
- **회원 기능:** 회원가입과 로그인을 지원하고 마이페이지에서 지난 분석 기록을 볼 수 있습니다.

## 기술 스택

- **Backend:** Python / Django 5.2 / SQLite
- **AI / ML:** OpenAI Whisper (medium) / Hugging Face Transformers / PyTorch / scikit-learn
- **감성 분석 모델:** beomi/kcbert-large (파인튜닝) / klue/roberta-large (비교 실험)
- **음성 추출:** yt-dlp
- **Frontend:** Django Template / JavaScript / CSS

## 실행 방법

Whisper와 yt-dlp를 사용하려면 ffmpeg가 따로 설치되어 있어야 합니다.

```bash
# 1. 패키지 설치
pip install -r requirements.txt

# 2. DB 생성 및 유해 단어 사전 등록
python manage.py migrate
python manage.py import_badwords

# 3. 관리자 계정 생성 (검수 기능을 쓸 때)
python manage.py createsuperuser

# 4. 개발 서버 실행 (PowerShell 기준이며 로컬에서는 DEBUG를 켜고 실행)
$env:DJANGO_DEBUG = "True"; python manage.py runserver
```

환경변수 목록은 [.env.example](.env.example)에 정리해 두었습니다.
